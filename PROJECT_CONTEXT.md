## Что это за проект

Forma — персональный offline-first PWA-дневник тренировок без регистрации, сервера и авторизации. Основное устройство — Android-смартфон пользователя. Интерфейс сейчас развивается как mobile-first продукт с крупными зонами нажатия, свайпами и минимальным количеством действий.

## Предпочтения пользователя

- Общение и интерфейс — на русском языке.
- Приоритет: удобство на Android, минимум касаний, крупные touch-targets, свайпы.
- Визуальный стиль: тёмный premium AI dashboard, glassmorphism, мягкое синее/фиолетовое свечение, много воздуха, Bento-карточки.
- Пользователь предпочитает быстро видеть готовый результат и редактировать по факту.
- Не возвращать старый фитнес-дизайн и не перегружать дашборд шумными карточками.

## Критические правила данных

- Все пользовательские данные находятся только в IndexedDB браузера через Dexie.
- Нельзя очищать IndexedDB, менять имя базы или выполнять миграцию с потерей данных.
- Данные установленной PWA на телефоне не синхронизируются с ПК автоматически.
- Экспорт/импорт резервной копии находится в настройках.
- Серые прошлые значения в активной тренировке — только `placeholder`. Они не записаны в текущий подход и не влияют на объём, пока пользователь сам не введёт данные.

## Текущее поведение приложения

### Активная тренировка

- При запуске раскрыто только первое упражнение, остальные свернуты.
- Нажатие по всей шапке упражнения раскрывает/сворачивает его.
- Подход удаляется свайпом влево.
- Новый подход всегда создаётся с пустыми реальными значениями.
- Ввод с Android-клавиатуры: вес → «Перейти» → повторы → «Перейти» → автоматическая галочка → вес следующего подхода.
- После выполнения всех существующих подходов карточка целиком становится тёмно-зелёной и автоматически сворачивается.
- Добавленные вручную подходы учитываются: упражнение завершится только после выполнения каждого из них.
- Прошлые вес и повторы последней завершённой тренировки того же шаблона показаны серыми placeholder-подсказками.
- Таймер отдыха может быть полностью отключён; настройка применяется к новым упражнениям.
- Кнопка завершения тренировки находится под всеми упражнениями.
- После сохранения результата открывается `/workouts/history`.

### История и шаблоны

- Шаблоны можно сортировать Drag&Drop; порядок хранится в IndexedDB.
- Шаблоны и завершённые тренировки удаляются с подтверждением/возможностью отмены там, где предусмотрено.
- История открывается отдельной вкладкой и маршрутом `/workouts/history`.
- Каждая завершённая тренировка раскрывается кнопкой: внутри компактно показаны все упражнения, выполненные подходы и объём.
- Свайп влево по строке истории удаляет тренировку после подтверждения.
- При попытке запустить другой шаблон во время активной тренировки появляется диалог; приложение больше не открывает молча неправильную сессию.

### Дашборд и статистика

- Карточка быстрого старта перелистывает шаблоны горизонтальным свайпом.
- «Ритм тренировок» удалён с дашборда.
- Последняя тренировка на дашборде показана компактной строкой с длительностью.
- 1RM удалён из интерфейса.
- В статистике последняя тренировка выбранного упражнения показывает подходы и объём с мобильным выравниванием влево.

### PWA

- PWA установлена на телефоне пользователя.
- Есть PNG-иконки, safe-area и мобильная нижняя навигация.
- После нового деплоя пользователь обычно должен полностью закрыть PWA и открыть снова либо принять предложение обновления.
