# Forma

Персональный offline-first PWA-дневник тренировок.

## Возможности

- шаблоны тренировок и Drag&Drop упражнений;
- активная тренировка с автосохранением каждого подхода;
- автоматическая подстановка прошлых весов и повторений;
- таймер отдыха, история упражнений и расчёт объёма;
- статистика, интерактивные графики и расчётный 1RM;
- экспорт и восстановление полной резервной копии;
- установка как PWA и работа без интернета.

Данные находятся только в IndexedDB текущего браузера. Для переноса или сохранности используй экспорт в разделе «Настройки».

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:4173`.

## Проверка

```bash
npm run typecheck
npm run test
npm run build
npm run preview
```

## Структура

- `src/app` — инициализация, маршруты и глобальные стили;
- `src/components` — переиспользуемые UI-компоненты;
- `src/pages` — экраны приложения;
- `src/features` — изолированные функции, например таймер;
- `src/storage` — IndexedDB, репозитории, backup и миграции;
- `src/widgets` — крупные интерфейсные блоки;
- `src/types` и `src/utils` — доменная модель и чистые вычисления.
